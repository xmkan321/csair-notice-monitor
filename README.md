# 南航公告监控系统

每天 8:00-24:00，每 30 分钟自动检查南方航空官网公告页面，发现新公告通过飞书机器人推送通知。

## 工作原理

1. GitHub Actions 每 30 分钟触发一次（北京时间 8:00-24:00）
2. Python 脚本调用南航 API 获取最新公告列表
3. 对比 `state.json` 中已记录的公告 ID
4. 发现新公告 -> 飞书机器人推送卡片通知
5. 失败自动重试（最多 3 次，间隔 5 分钟）
6. 连续 3 次失败 -> 飞书推送告警

## 配置

在仓库 Settings -> Secrets and variables -> Actions 中添加：

- `FEISHU_WEBHOOK`: 飞书自定义机器人 Webhook 地址
